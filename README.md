# App Store Listing Counter

A free, in-browser counter for store listing copy. Nothing is uploaded: the text never leaves your browser.

## What it does

- App Store fields with live counts: name (30), subtitle (30), promotional text (170), keywords (100) and description (4,000)
- Google Play fields with live counts: title (30), short description (80) and full description (4,000)
- Counts characters correctly for Chinese, Japanese and Korean (and for emoji), using grapheme clusters rather than bytes
- Bars and remaining counts turn amber near the limit and red when you go over
- App Store keyword checker: flags duplicate keywords, empty tokens, and whitespace (Apple recommends commas and no spaces)
- Copy any field, copy cleaned keywords, or copy a whole store's fields at once
- The interface is available in English and 中文

## How to use

1. Open the tool and choose **App Store** or **Google Play**
2. Type or paste each field; the counter updates as you type
3. For App Store keywords, enter comma-separated terms. If spaces or duplicates appear, use **Apply cleaned keywords** or **Copy cleaned keywords**
4. Use **Copy** on any field when you are ready to paste into App Store Connect or Play Console
